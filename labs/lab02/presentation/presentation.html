# Цель
Показать, как работают три шифра перестановки, и как их запустить из командной строки Julia.

# Состав работы
1) Столбцовая перестановка (пароль задаёт порядок столбцов).  
2) Решётка Флейснера (повороты 0/90/180/270°, блочная обработка).  
3) Шифр Виженера (посимвольные сдвиги по ключу).

# 1. Столбцовая перестановка — идея
- Пишем текст по строкам в таблицу `rows × cols` (без пробелов).  
- Сортируем буквы ключа; читаем столбцы в этом порядке.  
- Если таблица не заполнилась — добавляем `_`.

# 1. Столбцовая — запуск
```
julia route.jl "this is a test message!" water 4 5
→ hamgses!iss_iteetsta
```
- Здесь ключ `water`, размер 4×5.  
- Регистр/пунктуация сохраняются в том виде, как попали в таблицу.

# 2. Решётка Флейснера — идея
- Размер матрицы \(2k \times 2k\); дырки заданы в квадранте \(k \times k\).  
- Четыре поворота на 90° дают покрытие всех \(4k^2\) позиций.  
- Блоки текста длиной \(4k^2\) пакуются последовательно; при нехватке символов — паддинг.

# 2. Решётка — запуск
```
julia rails.jl "Hello, New World!" keys 2
→ ,lr!HNdwoeolle W
```
- Ключ `keys` сортирует столбцы.  
- Для `k=2` размер блока \(4k^2 = 16\). При необходимости остаток дополняется.

# 3. Виженер — идея
- Алфавит по умолчанию: a–z (можно передать свой).  
- Для каждой буквы текста используем индекс буквы ключа (ключ повторяется).  
- Неалфавитные символы перепечатываются без изменений.

# 3. Виженер — запуск
```
julia vigener.jl e "hello world" key
→ rijvs uyvjn
julia vigener.jl d "rijvs uyvjn" key
→ hello world
```

# Практические замечания
- Убедитесь, что длина текста подходит под параметры (rows×cols, 4k²).  
- Для кириллицы в Виженере передайте алфавит: `"абвгдежзийклмнопрстуфхцчшщъыьэюя"`.  
- Параметры можно подбирать для демонстрации эффектов перестановки.
