# Цель

Понять, как работают базовые шифры перестановки, и реализовать три метода на Julia: столбцовая перестановка, решётка Флейснера и Виженер.

# Теория (кратко)

- **Столбцовая перестановка с паролем.** Открытый текст записывается в таблицу построчно. Порядок чтения столбцов задаётся сортировкой символов пароля (при равенстве — по позиции). Так получается шифртекст.
- **Решётка Флейснера.** Для размера \(2k \times 2k\) задаётся набор дырок \(k \times k\). Последовательно поворачивая решётку на 90° и подставляя дырки, заполняем блок из \(4k^2\) символов. Для последнего блока возможна дозащита спецсимволом (паддинг).
- **Виженер.** Буквы заменяются циклическими сдвигами по индексу буквы ключа. Ключ повторяется по длине текста. Пунктуация/пробелы не меняются.

# Параметры запуска

- **route.jl**: `julia route.jl "<текст>" <ключ> <строки> <столбцы>`  
- **rails.jl**: `julia rails.jl "<текст>" <ключ> <k> [<паддинг>]`  
- **vigener.jl**: `julia vigener.jl e|d "<текст>" <ключ> [<алфавит>]` (по умолчанию латиница)

# Реализация

## 1. Столбцовая перестановка (`route.jl`)

- Текст очищается от пробелов, при необходимости дополняется `_` до размера решётки.  
- Матрица размера `rows × cols` заполняется построчно.  
- Столбцы считываются в порядке `sortperm` по буквам ключа (устойчиво).

**Пример**
```
julia route.jl "this is a test message!" water 4 5
→ hamgses!iss_iteetsta
```

## 2. Решётка Флейснера (`rails.jl`)

- Для заданного `k` формируется решётка \(2k \times 2k\) с дырками в квадранте \(k \times k\).  
- Блок текста длиной \(4k^2\) распределяется по позициям через четыре поворота на 90°.  
- Затем столбцы читаются по порядку букв ключа; последний блок дополняется `паддинг`-символом (по умолчанию “я”).

**Пример**
```
julia rails.jl "Hello, New World!" keys 2
→ ,lr!HNdwoeolle W
```

## 3. Виженер (`vigener.jl`)

- Индекс буквы берётся из выбранного алфавита (по умолчанию a–z).  
- Шифрование: \(C = (P + K) \bmod n\), дешифрование: \(P = (C - K) \bmod n\).  
- Регистр сохраняется, неалфавитные символы не меняются.

**Пример**
```
julia vigener.jl e "hello world" key
→ rijvs uyvjn
julia vigener.jl d "rijvs uyvjn" key
→ hello world
```

# Тестирование и соответствие коду

- Все примеры выше получены указанными файлами `route.jl`, `rails.jl`, `vigener.jl` без изменений параметров.  
- Исключения: если длина текста меньше блока решётки, включается паддинг; если не хватает символов для матрицы столбцовой перестановки, добавляются `_`.
